# Projects

Projects are the central organizing unit in DETI Maker Lab. All equipment requisitions are attached to a project.

---

## Creating a project

1. Navigate to **Projects** in the navigation bar.
2. Click **New Project** (or equivalent button).
3. Fill in the project details:
   - **Name** — required.
   - **Description** — optional but recommended.
   - **Course** — the course this project belongs to (optional).
   - **Academic year** — optional.
   - **Group number** — optional.
   - **Tags** — optional keywords.
   - **Links** — optional related URLs.
4. Submit the form.

The project is created with status `pending`. A lab technician can change the status to `active` after review.

---

## Joining a project

You can join an existing project by invitation from the project leader, or (if enabled) by searching for projects and requesting membership.

Project members have one of the following roles:

| Role | Description |
|---|---|
| `leader` | Project creator or designated lead |
| `member` | Regular project member |
| `observer` | View-only access to the project |
| `advisor` | Advisor or mentor |
| `supervisor` | Supervisor or professor |

---

## Managing members

Project leaders can:
- View the current member list on the project detail page.
- Remove members.
- Change member roles.

---

## Project status

| Status | Meaning |
|---|---|
| `pending` | Created, waiting for technician review or activation |
| `active` | Active and operational; can submit requisitions |
| `rejected` | Project was rejected by technician review |
| `completed` | Project concluded |
| `archived` | Archived for record-keeping |

:::info
Only active projects can submit equipment requisitions. If your project is in `pending` status, contact your lab technician to activate it.
:::

---

## Viewing your projects

The **Projects** page lists all projects you are a member of. Click any project to see:
- Project details (name, description, course, status).
- Current members and their roles.
- Requisitions associated with this project.
